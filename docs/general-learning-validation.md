# 通用課程 v2：實作與驗證

日期：2026-09-05。這份紀錄對應通用課程改動，不代表已部署至 Render。

## 本輪結果

- Vitest：17 個測試檔、110 個案例全部通過。
- Playwright：75 個瀏覽器案例全部通過，包含四種新課程、既有網站 demo、手機版導覽、語音播放與恢復進度。
- Python：真實執行 `print(2 + 3)` 得到 `5`；手動停止、10 秒逾時、20,000 字元輸出上限與錯誤後重新執行均通過。
- TypeScript 型別檢查、Next.js 正式建置、Prettier 格式檢查全部通過。
- 獨立程式碼審查提出的 v2 補強節點與 `cd ..` 問題已修正並複查；瀏覽器測試發現的 v1 互動版型及準備畫面相容問題已補上回歸驗證。

## 已接通的流程

- 首頁傳遞學習目標與選定語言，模型依共用能力清單產生 v2 課程與整章教材。
- 需要調整目標範圍時，先顯示限制、預期成果及節點清單，確認後才準備教材。重新整理保留待確認狀態；重複確認不建立另一份章節，API 檢查課程擁有者。
- 純概念課程不顯示實作入口；網站直接編輯與預覽；Python 直接編輯與執行；Terminal 顯示虛擬檔案與命令結果。
- 練習保存與檢查走真正的 API、SQLite 與服務邏輯。執行 Python 本身不會標記完成；目前 Python 檢查點使用檔案內容或理解題，尚非 Python 測試案例評分。
- 內容與語音各有一條有界工作通道。慢速語音不阻止預取下一章；預取章節不自動合成語音。語音失敗不改教材，不自動重送付費請求。
- v1 固定網站課程保留原本 Terminal 與既有音訊相容流程。手動新增補強主題預設為概念型節點；模型推薦的補強節點需明確指定受支援環境。

## 能力界線

| 環境     | 支援                                                | 限制                                                                                                                                                       |
| -------- | --------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 純概念   | 說明、比較、步驟、流程圖、選擇題                    | 內容正確性仍需人工抽查                                                                                                                                     |
| 網站     | HTML、CSS、瀏覽器 JavaScript、即時預覽              | 不執行 npm、後端或部署命令；預覽沒有記憶體配額                                                                                                             |
| Python   | Pyodide 0.28.3、`.py` 檔、標準輸出與錯誤、停止      | 首次下載 CDN；不支援 pip、互動輸入、GUI、主機 shell 或一般網路存取。每次執行最多 10 秒，輸出最多 20,000 字元；沒有硬性記憶體配額，執行產生的檔案不寫回作品 |
| Terminal | `pwd`、`ls`、`cd`、`mkdir`、`touch`、`cat`、`clear` | 虛擬檔案系統，非 Linux OS；不支援旗標、管線、重新導向、套件安裝或程序管理                                                                                  |

講義的 HTML renderer 尚未接上下載入口；PDF 與講義匯出不在本次驗收範圍。

## 重現驗證

```powershell
npm.cmd test
npm.cmd run typecheck
npm.cmd run build
npx.cmd playwright test --config playwright.general.config.ts --reporter=line
```

瀏覽器測試需要已安裝 Chromium（`npx.cmd playwright install chromium`）。專用設定在 3100 埠啟動正式建置、背景 worker 和本機模型替身，使用系統暫存目錄中的獨立 SQLite；不讀寫日常 `.data` 課程，也不呼叫付費模型或語音服務。所有測試沿用真正的 API、服務與 UI。

只驗證四種新課程：

```powershell
npx.cmd playwright test --config playwright.general.config.ts general-course.spec.ts --reporter=line
```

這四種課程從首頁提交目標，經本機模型替身產生 graph／chapter，完成練習並重新整理恢復進度。Python 測試下載並執行真正的 Pyodide，不以假輸出替代。測試環境必須允許連線至 `cdn.jsdelivr.net`；若出現 `ERR_NETWORK_ACCESS_DENIED`，應解除測試執行環境的網路限制，不能把載入失敗視為 Python 通過。

單元與整合測試另涵蓋 scope 擁有權／去重、v2 補強節點、子目錄 `cd ..`、檔案初始化、workspace 衝突、舊課程與音訊、刪除課程後的晚到結果，以及「語音請求尚未回覆時下一章已備妥」的真實 worker 情境。
