# 課前提問、適應性學習路徑與延伸單元

依據使用者 2026-09-05 的需求整理。新建正式課程已實作五題課前了解、完整節點規劃、只生成當前章節、下一章深度建議與獨立延伸單元。節點學習紀錄仍保存於資料層；依使用者本次確認，個人筆記介面暫不開放。舊課程保留原本的章節與紀錄，體驗課程仍直接開啟。

目前難度調整採可追溯的保守規則：至少兩個不同檢核，首次通過率至少 80% 且無本章提問紀錄時加深一級；首次通過率不超過 50% 且至少兩次未通過時降低一級。基礎、應用、深入三種深度有上下限，可選擇維持原安排。提問紀錄表示本章使用過協助，並不等於逐題精確的提示測量。自動跳過節點、跨章能力推論及自動新增補強範圍尚未啟用；補強由使用者預覽確認後建立。以下保留完整產品設計方向。

## 1. 先了解學習者，再製作第一章

輸入目標後立即進入準備畫面，顯示「正在安排你的學習路徑」，接著詢問 3–5 個相關問題。回答前不顯示虛構的教材生成進度。

問題收集五個維度，依已知資訊減少重複：

| 維度           | Linux 例子                                 | 用途               |
| -------------- | ------------------------------------------ | ------------------ |
| 已有經驗       | 沒用過、操作過基本指令、已使用於工作       | 起點與先備知識     |
| 使用目的       | 日常操作、開發環境、伺服器管理、考試       | 課程範圍與終點     |
| 已會與卡點     | 熟悉檔案路徑嗎？最常卡在哪裡？             | 避免重教與漏教     |
| 期望深度       | 能完成任務、理解原理、深入分析             | 深度與練習複雜度   |
| 時間與切入方式 | 每次可花多久？希望從情境、原理或題型開始？ | 單元長度與呈現順序 |

每題提供精簡選項、可補充文字及「不確定」。學習者自述作為初始假設，後續以練習證據修正。必要背景依學習目標安排；歷史不固定成為所有課程的第一章。

課前問題應快速顯示，不等待整份教材生成。回答與目前題目位置需持久化，重新整理後能繼續。提交需防重複：只建立一次初始 Graph 與第一章工作。

流程：學習目標 → 3–5 題 → 初始 Learning Graph → 第一章 → 學習證據 → 更新未來路徑 → 製作下一章。

一次只製作目前需要的一個章節。未來節點保留規劃資料，不預先產生完整教材、練習或音訊。準備狀態分為了解需求、安排路徑、製作本章、準備語音；教材可閱讀時即可進入。

## 2. 詳細的 Graph、精簡的畫面

Graph 是可修訂的教學計畫。每個未開始節點包含：

- 明確學習目標與完成後可展現的能力。
- 核心概念、先備能力、可能誤解。
- 預計深度、時間、活動方式與驗證方式。
- 主線／延伸的關係、規劃原因與修訂版本。

圖上僅顯示短標題與節點內的小圖示。將目前常駐占用一列的「正在學習、已完成、補強路徑」圖例收進一個說明 icon，點擊或鍵盤操作時才展開。節點本身保留精簡狀態標記，不另占大型區塊。圖示需有可存取名稱，焦點或指向時顯示文字說明；狀態不能只靠顏色區分。點選節點後，以單一詳情面板展示內容，避免圖上塞滿摘要。

### 調整下一章的依據

記錄首次作答、重試、使用提示及實作完成證據，對應到具體核心能力。單次答錯或停留時間不直接等於程度不足。不同難度題目的答對率不直接當成同一尺度；已看過答案後答對也不等同首次獨立答對。

章節結束時決定：依原計畫前進、略過已掌握的重複內容、增加挑戰，或提出針對特定概念的短補強。證據不足時保持原深度，使用小檢查取得更多資訊。

只修訂尚未開始的節點。已完成的學習紀錄與正在使用的章節固定保留。每次修訂保留前後版本及理由，並提供簡短說明，例如「你已能獨立處理相對路徑，下一章將增加多層目錄的情境」。學習者可以選擇維持原安排。

一般難度微調可直接提供建議；新增實質範圍、明顯增加時間、或改變原學習目標時，先展示具體差異讓學習者決定。這是產品交互要求，不是開發操作的權限要求。

## 3. 延伸領域作為真正的支線

主線 A → B → C 保持不變。從 B 延伸的單元顯示為 B → E1 → E2 的支線；選擇進入後，學習者完成這段延伸再返回主線。

「從哪個節點延伸」和「返回哪個學習位置」是兩個獨立資料。即使從已完成節點建立延伸，也不應改寫目前主線進度。進入支線時保存主線節點、頁面、已完成活動與作品狀態；返回時恢復該位置。支線的實作材料應有獨立範圍，除非活動明確要求延續同一作品。

新增流程：

1. 選取來源節點，描述想延伸的主題。
2. 詢問想理解到什麼程度；用具體能力描述淺入門、能應用、深入原理，允許補充目標。
3. 顯示支線預覽：與原概念的關聯、先備知識、各節點目標、預估時間，以及返回位置。
4. 學習者選擇現在進入或保留稍後學習；確認後才建立正式支線。

系統需檢查主題關聯、重複範圍、先備能力、可用實作工具與支線大小。不要把任何輸入直接轉成一個模糊節點。延伸單元數量依深度決定，受合理大小限制；超大範圍先提出較聚焦的規劃。

支線可以完成、暫停或退出，主線仍可繼續。規劃圖上的關係和學習者目前選擇的執行路線分開保存，避免同時存在多條邊時以第一條邊猜測下一步。重複提交、重新整理及失敗重試不得重複加入節點。

## 4. 節點筆記與學習軌跡

未開始節點顯示「預計學習內容」，已學節點顯示以實際課程和活動紀錄為依據的筆記：

- 核心重點與必要原因。
- 代表性例子、使用過的圖解或實作成果。
- 學習者提出的問題、實際作答與訂正過程。
- 容易混淆之處、使用過的提示、仍待複習的能力。
- 與先前概念和後續延伸的連結。
- 學習者可編輯的個人心得。

系統只能記錄已發生的提問與回答，不能自行編造「學生當時如何思考」。推測性摘要需要清楚標示並允許更正。保存摘要對應的章節版本，避免後續規劃更新使舊筆記失去上下文。自動摘要不能覆蓋個人筆記。

學習曲線依概念呈現已練習、首次獨立完成、提示後完成與待補強等證據。查看歷程時能追蹤變化及相關作答，不以閱讀完成率冒充掌握程度。

## 5. 實作範圍與驗收

這次變更涉及課程狀態、Graph 結構、章節生成排程、進度事件與 Learning Map；需要一起調整，不適合只修改地圖畫線。

- 課前提問：尚未提交完整回答時不生成教材，刷新可恢復，提交只生成一章。
- 路徑調整：相同證據輸入有可解釋的決策；不反覆升降難度；不改寫已完成／正在學習的內容。
- 支線結構：新增延伸不刪除主線邊；能從過去與末尾節點建立；進入／返回／重試皆不遺失進度或作品。
- Graph 畫面：桌面與手機可辨識節點狀態、關係與目前位置，詳細內容按需展開。
- 節點筆記：區分規劃與實際學習內容，可保存個人筆記，有來源紀錄，重新整理後完整保留。
- 既有課程：舊版線性 Graph 與補強路徑仍可讀取，不重新解釋舊紀錄或強制清空學習進度。
- 效能：分別量測問題顯示、Graph 規劃、本章內容及語音時間，不以偽造百分比或省略必要評量掩蓋等待。
