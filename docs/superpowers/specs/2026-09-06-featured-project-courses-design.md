# Methelia：20 門專題式精選課程與共用教學元件

狀態：設計提案，待確認；尚未實作或上架。

## 產品目標

每門課帶使用者完成一件可檢查的作品、實驗或決策。沿著同一件作品理解背景、概念、技術與實作；章節不是互不相干的知識展示。完成後保留作品、參數與學習進度，能回來修改和複習。

首批共 20 門，分四批各五門製作與驗證。首頁展示跨領域的代表課程，Explore 提供完整 20 門與領域篩選。只有完整驗證的課程才標記可學習；不使用假課程數、假觀看數或未完成入口。

## 教學路徑

每門約 5–7 章，每章 3–6 個有明確目的的教學頁，依作品需求調整。

1. 看見成果及真實問題；用必要的歷史背景說明為何需要這項技術。
2. 操作直觀模型，建立接下來實作所需的概念。
3. 觀看老師逐步示範，理解每個操作與結果的關係。
4. 逐步完成作品，穿插預測、實驗與立即回饋。
5. 用新條件測試作品、修正錯誤，說明限制與取捨。
6. 完成成果與回顧，提供有意義的延伸路徑。

歷史不強制成為冗長獨立章節。不是每頁都互動；圖片、圖解、短動畫、必要的真實影片及精簡文字各自服務學習目標。

## 元件庫與內容格式

在既有 component schema、能力目錄與 LessonSection 播放流程上擴充，避免建立另一套不相容播放器。

- 共用基礎：全版教學舞台、參數控制、即時讀值、老師指標／操作示範、時間軸、成果檢查及作品匯出。
- 表現元件：2D 座標與函數、3D 場景與切片、圖與尋路、粒子／碰撞、軌道、電路、波形音訊、圖表、配色、排版畫布、關鍵影格動畫、因果與資源模擬、邏輯閘。
- 每個元件保存穩定識別碼、版本、參數 schema、支援操作、狀態格式、檢查規則、示範資料、中英文文案與範例。
- 領域計算與視覺呈現分離；可以直接測試數學與物理規則。數值模擬限定步長、速度與數值範圍，暫停後停止計算。
- 生成器只能選擇已註冊的元件與受驗證參數。未知元件或不支援任務須報錯修復，不能默默換成文字頁或執行任意生成程式碼。
- 互動狀態按使用者、課程、章節、頁面隔離保存。切頁、重整和重新開啟後可以續作，重設只影響目前實驗。
- 精選內容、腳本、素材引用與版本放入版本控制；大型音訊／影片使用可持久化的資產儲存與 manifest。課程內容更新不直接覆寫學習者作品。

## 開源採用策略

採用成熟的基礎繪圖或模擬函式庫，加上 Methelia 自己的教學介面與內容格式。選型時檢查官方文件、授權、維護狀況、體積及瀏覽器支援，固定版本並保存授權聲明。

已查看 OpenMAIC 官方網站及 GitHub：目前 README 描述 PBL、互動內容、素材 registry 與課程修訂流程，可參考其分工。尚未完成元件逐項原始碼與授權審查，不能宣稱已選用其元件。保留 Methelia 的連續操作舞台與專題流程。

候選方向：3D 使用成熟場景引擎；2D／圖表優先使用 SVG 或 Canvas；物理先針對明確模型實作可驗證計算。實際套件在工程設計階段確認。

參考：https://github.com/THU-MAIC/OpenMAIC 、 https://open.maic.chat/

## Python 網站與執行環境

目前 Python 是瀏覽器 Pyodide worker，支援受限的真實 Python 與標準函式庫；沒有 Flask 伺服器、pip、網路或互動 input()。

首批 Python 網站課程採「Python 產生靜態 HTML 网站」：擴充受限的輸出檔案回傳，預覽經 sandbox 隔離的 HTML，提供檔案下載；教學清楚區分產生靜態網站與執行後端伺服器。文字冒險以可重放的行動輸入測試，不使用目前無法工作的 input()。

若要加入真正的 Flask／Django 課程，另行建置每位學習者隔離的後端執行環境，再上架該課；不在目前 Render 應用主程序直接執行學習者程式。

## 視覺與播放規則

- 教學主要區域占可用畫面的大部分，取消外層包覆卡片與過大的標題區。
- 桌面主要文字目標 20–22px；統一標題、內文、控制項層級，窄螢幕依內容重排。允許必要的程式編輯器內部捲動，不以截斷內容維持一頁。
- 保留單章完整語音與分頁時間點；手動下一頁自動播放，頁尾自動暫停，互動實驗可獨立暫停與重設。
- 字幕獨立浮層、不改變內容高度；控制欄收起時字幕同步下移並保留底部 padding。
- 老師的拖曳、輸入及參數改變要可見、可重播；學生開始操作時不被老師自動覆寫。
- 波形聆聽須由使用者操作啟動，設合理音量；減少動態偏好、鍵盤操作與觸控提供可用替代方式。
- 所有課程、檢查回饋、元件控制及旁白提供英文與繁體中文。

## 上架流程與驗收

先完成兩門垂直樣板（互動作品集、方程式探索器），跑通內容 → 元件 → 進度 → 作品 → 旁白 → 精選入口；再擴充其他元件與 20 門課。這是製作順序，總交付目標仍是 20 門。

每門上架前：章節與前置關係完整、實作真能完成、成果檢查有效、錯誤回饋指出差異、素材載入成功、語言一致、旁白與示範對齊、重整可續作、版面不遮擋、console 無相關錯誤。

共用元件驗證：幾何方程、碰撞動量與動能、軌道數值誤差、機率邊界、電路與邏輯真值；同時覆蓋滑鼠／觸控／鍵盤及暫停／重設。

精選課程預先製作並驗證，學習者開啟時不觸發整堂重生成。資源依課程載入，共用套件與音訊快取。首頁不一次啟動所有 3D 畫布或載入全部課程音訊。

保留工作區既有 Learning Map／提前生成修改。分批提交功能與內容，完成整合驗證後合併 main；最後確認 Render 的部署分支切換與持久化資產可用，再部署並從正式網域測試。
