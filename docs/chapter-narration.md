# 整章語音與頁面時間軸

依據 2026-09-05 的播放需求，章節所有 script entries 以換行串成完整旁白，一次呼叫語音供應商。回傳對齊資料保留各頁的絕對起訖時間，音檔只存一份。頁面分隔依實際語音時間定位，不平均切割音訊。

- 新章節與手動重建使用 `narrationMode: chapter`，不建立 `pageAudio`。
- 本頁旁白結束時自動暫停並停留在本頁，保留觀察和練習時間；不自動切到下一頁。同一章仍保留同一個 audio 元素。再按播放可重播本頁，按下一頁才切換並自動播放。
- 點上一頁／下一頁會保存實作與進度，從目標頁起點自動播放。
- 點下一章會保存當前進度，等目標章節音訊準備完成後播放。重新整理不保留這次自動播放意圖，轉去複習會取消它。
- 手動拖曳、點頁面標記或倒退十秒會暫停並切到對應頁面，按播放後接續。拖曳結束再提交目標位置。
- 章節完成條件仍由實際練習控制；聽過旁白不會自動算作答通過。
- 既有已生成音訊保留，提供「改用整章語音」操作以新 package 重建。未生成的舊頁面音訊可直接改用整章；部分完成的舊音訊需手動重建，避免混合兩種格式。

播放速度、靜音、字幕與老師示範保留。若瀏覽器拒絕自動播放，顯示手動播放提示。一次完整合成減少逐頁請求，但總等待時間仍依章節長度與供應商回應而定。

播放中若約 2.5 秒沒有操作，控制列滑出且畫布擴展。滑鼠、觸控、键盤操作或自動暫停會恢復控制列；鍵盤焦點、文字輸入或拖曳時保留操作介面。這是介面內的沉浸顯示，瀏覽器原生全螢幕仍由全螢幕按鈕進入。

目前不做旁白中途的語意暫停點。音訊時間更新以外還有獨立邊界檢查，避免稀疏 timeupdate 事件讓播放越過本頁。

字幕透過 portal 放在課程容器內的獨立絕對定位圖層，不占用內容高度，也不攔截點擊。開關字幕不改變內容間距；播放欄收合時，字幕與播放欄以相同時間往下移動一個播放欄高度，字幕留在畫面底部。播放欄展開時兩者同步返回。原生全螢幕也包含字幕圖層。

驗證：153 項單元／整合測試通過。第一輪 15 項瀏覽器測試涵蓋所有實作環境、Python 停止與逾時、頁末停留和播放欄收合；最後 8 項針對音訊、鍵盤、時間分界空白與 Python 跨頁共用環境的測試亦通過。測試使用原生瀏覽器音訊及實際 Pyodide，不呼叫付費模型或語音。
